How to implement Copy and Clone for a struct with String

A type containing a String cannot implement Copy because String owns heap memory and requires Drop.

Implement Clone instead to duplicate heap-allocated data explicitly when needed.

#[derive(Clone)]
struct Record {
    label: String,
}
