We evaluate deterministic write-ahead log batching across NVMe storage pools using a zero-copy sequencer pipeline. Full artifacts are linked in the archival PDF.

5. Latency and Throughput Model #

Analytical steady-state throughput obeys \text{throughput} = \frac{N \cdot B}{T_{\text{commit}} + T_{\text{sync}}} throughput = (N*B)/(T_commit + T_sync) and is valid only for batch size N >= 64 where ring amortization dominates syscall overhead.
